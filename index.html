Computability Workbench

LOOP · WHILE · PRIMREC

version 0.3

Write and run programs in the small models of computation from the lecture Theoretische Informatik: LOOP programs, WHILE programs and primitive recursive functions. Choose a language and an example, enter inputs and press Run. Turn on Trace to follow the computation step by step, or state what a program should compute and test it under Verification. Everything runs in your browser, and your programs are stored locally.

    Verification
    

      
      
    

    
Header lines, in this order (after INPUT and OUTPUT):
  REQUIRES <condition>     optional: only test inputs satisfying the condition
  ENSURES  <condition>     must hold after the program has finished

Use the names from INPUT and OUTPUT (default: inputs x1, x2, …, result x0).
Inputs refer to their initial values.
Operators, from loosest to tightest:
  <==>   ==>   OR   AND   NOT   == != < <= > >=   + -   * / %   ^
  IF c THEN a ELSE b    e.g.  ENSURES r == IF x >= y THEN x - y ELSE 0
Numbers and conditions are kept apart: IF, AND, OR, NOT, ==> and <==> need
conditions such as comparisons, and a whole REQUIRES/ENSURES line must be a condition.
"Check" runs the program on all inputs up to the given maximum. This is testing, not a proof.

  

  

    Your programs
    

      Every program you write or change is stored in this browser and listed under
      "Your programs" in the Example menu. It is not stored anywhere else.
      
      To keep a copy, or to move your programs to another browser or computer, export them to a file.
      When importing, you choose which programs to take over; programs you already have are
      only replaced if you say so.
